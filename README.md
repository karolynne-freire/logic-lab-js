## 🎯 Metas de Melhorias e Evolução

### 🔢 Jogo do Número Secreto
- [ ] Adicionar efeitos sonoros personalizados  
- [ ] Criar modo “difícil” com números até 100  
- [ ] Exibir histórico de tentativas  
- [ ] Melhorar design com tema escuro e animações sutis  

### 🎲 Sorteador de Números
- [ ] Separar funções de *reset* e *habilitação* do botão “Reiniciar”  
- [ ] Adicionar validações visuais  
- [ ] Mostrar resultado com animação ou efeito de fade  
- [ ] Melhorar design com cores mais contrastantes e tipografia mais legível  

### 🎮 AluGames
- [ ] Substituir IDs fixos por `data-attributes`  
- [ ] Exibir alerta ou badge visual quando o jogo estiver alugado  
- [ ] Adicionar contador de jogos alugados  
- [ ] Atualizar layout para visual moderno  

### 🛒 Carrinho de Compras
- [ ] Corrigir exibição do preço total (`R$`)  
- [ ] Verificar quantidade mínima (não permitir 0 ou negativo)  
- [ ] Implementar botão para remover itens individualmente  
- [ ] Melhorar layout com grid ou flexbox  
- [ ] Mensagem “Carrinho vazio” quando não houver produtos  

### 🎟️ Ingresso Online
- [ ] Unificar funções de compra em função dinâmica  
- [ ] Adicionar mensagem de confirmação visual  
- [ ] Permitir devolução/cancelamento de ingressos  
- [ ] Design limpo com ícones e cores modernas  

### 🎁 Amigo Secreto
- [ ] Limpar campo antes de cada novo sorteio  
- [ ] Adicionar botão para remover nomes  
- [ ] Aviso visual se tentar sortear sem nomes suficientes  
- [ ] Animação de “embaralhamento”  
- [ ] Design vibrante e responsivo  

### 🧩 Desafios Complementares
- [ ] Criar versões otimizadas com código mais enxuto

- [ ] Aplicar CSS customizado para visualização clara

## ⚡ Como Rodar o Projeto

1. Clone o repositório:  
```bash
git clone https://github.com/SEU-USUARIO/logic-lab-js.git
````

2. Entre na pasta do projeto:

```bash
cd logic-lab-js
```

3. Abra qualquer arquivo `.html` no navegador:

* **Windows:** clique duas vezes no arquivo ou `Ctrl + O`
* **Mac/Linux:** clique duas vezes no arquivo ou `Cmd + O`

4. Opcional: rodar em servidor local (para funcionalidades JS avançadas):

```bash
# Node.js
npx serve
# Python
python -m http.server 8000
```
